1. PRE-RECORDING SETUP & HARDWARE CALIBRATION CHECKLIST
================================================================================
Complete these checks before hitting record or beginning patient setup:

[ ] 1. AUDIO INPUT VERIFICATION
       - Ensure microphone / headset is connected and selected in Windows.
       - Audio meter in GUI should register baseline ambient noise.

[ ] 2. RUN 2-SECOND AMBIENT CALIBRATION
       - Click button: [Calibrate (2s)] on the Voice Console.
       - Operator action: Remain COMPLETELY SILENT for 2 seconds.
       - System action: Samples ambient room noise floor (e.g., -56 dBFS) and
         automatically sets the dynamic trigger threshold (typically +12 dBFS
         above ambient, clamped between -55 dBFS and -25 dBFS).
       - Verification: Ensure yellow threshold line in dBFS meter settles
         neatly above background room hiss.

[ ] 3. VERIFY MICROPHONE TOGGLE
       - Button reads: [Mic ON] (Green / Nominal).
       - Clicking toggles to [Mic OFF] (Red / Danger) to manually mute.

[ ] 4. INTERNET CONNECTIVITY CHECK
       - "ID Online" & "Dictation ID" require active internet (Google ASR).
       - "EN Offline" runs locally via Vosk (or falls back to Google ASR).

2. HALF-DUPLEX PROTOCOL & UI BADGE STATES
================================================================================
OR-SterileAssist implements strict Half-Duplex acoustic feedback protection to
prevent the microphone from hearing and re-triggering on its own TTS voice or
high-priority IEC 60601-1-8 medical alarm earcons.

UI BADGE READOUTS (Top-Right of Voice Console):

  [LISTENING]     (Green)
  - Microphone is active and awaiting surgeon speech.
  - RULE: ONLY speak commands when this badge is GREEN.

  [TTS SPEAKING]  (Amber)
  - The workstation is currently vocalizing synthesized speech or playing
    an auditory confirmation / alarm tone.
  - The microphone input buffer is automatically purged and muted.
  - RULE: PAUSE and DO NOT speak while this badge is displayed!

  [MIC OFF]       (Red)
  - Microphone manually muted by operator or hardware disconnected.

3. ASR OPERATING MODES OVERVIEW
================================================================================
Select via segmented buttons on the Speech Console:

  [ID Online]    -> Google Web Speech (id-ID)
                    Optimized for Indonesian surgical and CT viewport commands.
                    Provides natural spoken Indonesian TTS responses.

  [EN Offline]   -> Vosk Kaldi Recognizer (en-US)
                    Constrained offline surgical grammar (zero latency, offline).
                    Auto-falls back to Google en-US if Vosk model is loading.

  [Dictation ID] -> Free-Form Speech-to-Text (id-ID)
                    Transcribes clinical narratives directly into the
                    Intra-Operative Clinical Log editor.

6. CLINICAL DICTATION MODE (MODE: Dictation ID)
================================================================================
Purpose: Hands-free intra-operative surgical note recording without touching
keyboard or mouse in the sterile zone.

How It Operates:
1. Select [Dictation ID] on the Speech Console.
2. Confirm badge reads [LISTENING].
3. Speak surgical findings clearly in Indonesian.
4. Voice engine captures phrase on 0.7-second natural speech pause.
5. Transcribed text is timestamped and automatically appended to:
   "INTRA-OPERATIVE CLINICAL LOG".

REAL-WORLD CLINICAL PHRASES TO SPEAK IN DEMO:

  Example 1: Craniotomy Opening
  "Insisi kraniektomi frontotemporoparietal sinistra telah dilakukan. Dura dibuka secara melingkar. Perdarahan epidural minimal terkontrol."

  Example 2: Lesion Identification
  "Lesi tumor teridentifikasi pada lobus frontal kanan ukuran dua kali tiga sentimeter berbatas tegas."

  Example 3: Hemostasis & Closure
  "Hemostasis tercapai dengan bipolar dan surgicel. Tidak ada perdarahan aktif. Persiapan penutupan dura mater."

LOG CONTROLS IN WORKSTATION:
- [Speak Log]    : Uses Indonesian neural TTS to read back all logged notes.
- [Export (.txt)]: Saves complete timestamped surgical record to file.
- [Esc Key]      : Exits text cursor focus back to workstation hotkeys.

8. TROUBLESHOOTING & OPERATOR HINTS
================================================================================
Issue: System repeats or loops speech back to itself.
Cause: Speaking too quickly while TTS is talking.
Fix:   Wait for the badge to turn GREEN [LISTENING] before speaking!

Issue: Words appear on screen in "HEARD:" but command doesn't execute.
Cause: Spoken phrase didn't contain an exact recognized keyword from the table.
Fix:   Stick to concise triggers: "iris berikutnya", "jendela otak", "simpan".

Issue: High ambient noise (suction / cautery) causes false triggers.
Cause: Threshold too low.
Fix:   Hit [Calibrate (2s)] while suction machine is idling, or manually mute
       via [Mic ON/OFF] when not issuing commands.

Issue: English Vosk recognizer unresponsive.
Cause: Vosk English model folder missing or still downloading.
Fix:   System auto-falls back to online Google en-US recognition without
       freezing the interface. Ensure internet connection is active.
