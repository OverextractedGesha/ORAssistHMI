================================================================================
                OR-STERILEASSIST v2 — PANDUAN PENGGUNAAN CEPAT
         Workstation Ruang Operasi Bedah Saraf Nirsentuh (PySide6 + CT)
================================================================================

Paket rilis ini berisi OR-SterileAssist v2 (PySide6 Medical Workstation dengan
volume Real Clinical Cranial Lesion CT, Slice 101/149) serta fallback v1
(Tkinter). Model AI (MediaPipe Hand & Face) sudah disertakan offline di folder
"models/", dan dataset CT klinis nyata tersedia di folder "assets/".

--------------------------------------------------------------------------------
1. CARA MEMULAI (QUICKSTART WINDOWS)
--------------------------------------------------------------------------------

[LANGKAH 1] SETUP DEPENDENSI (Hanya Perlu Dilakukan Sekali)
- Pastikan laptop terhubung ke internet dan Python 3.10+ sudah terpasang
  (saat instalasi Python, centang "[X] Add Python to PATH").
- Dobel klik file:
    "1_SETUP_DEPENDENCIES.bat"
- Script otomatis akan:
  1. Membuat Virtual Environment lokal terisolasi (.venv) di folder ini.
  2. Memperbarui pip dan menginstall seluruh dependensi di requirements.txt
     (termasuk PySide6, nibabel, OpenCV, MediaPipe, SoundDevice, ASR/TTS).
- Tunggu hingga muncul pesan "SETUP BERHASIL SELESAI!".

[LANGKAH 2] JALANKAN APLIKASI
- Untuk OR-SterileAssist v2 (Rekomendasi Utama - PySide6 Workstation):
  * Opsi A (Dengan Log Konsol): Dobel klik "2_JALANKAN_APLIKASI_V2.bat"
    -> Menjalankan src\or_sterile_assist_v2.py beserta jendela terminal log.
  * Opsi B (Tanpa Jendela CMD): Dobel klik "3_JALANKAN_V2_TANPA_CMD.vbs"
    -> Menjalankan workstation v2 secara senyap via pythonw.exe tanpa jendela CMD.
- Untuk OR-SterileAssist v1 (Legacy Tkinter Fallback):
  * Dobel klik "2_JALANKAN_APLIKASI_V1.bat" -> menjalankan src\or_sterile_assist.py.

[LANGKAH 3] CITRA CT KLINIS DEFAULT (SLICE 101 / 149)
- Saat v2 dibuka, sistem otomatis memuat volume Real Cranial Lesion CT
  (149 irisan aksial 224x224, `assets/real_head_ct.npz`) dan langsung menuju
  Slice 101 (posisi lesi fokal hiperdens, rentang lesi slice 41-136).
- Anda dapat beralih antara "REAL CRANIAL CT", "SYNTHETIC PHANTOM" (60 slice),
  atau memuat berkas `.nii` / `.nii.gz` melalui tombol di panel CT.

--------------------------------------------------------------------------------
2. PANDUAN 6 GESTUR TANGAN BEDAH (SURGICAL HAND GESTURES)
--------------------------------------------------------------------------------
Arahkan tangan menghadap webcam pada jarak sekitar 0.5 - 1.2 meter:

1. PINCH (Cubit Telunjuk & Ibu Jari)
   - Tempelkan ujung ibu jari dan jari telunjuk, lalu gerakkan tangan naik/turun.
   - Fungsi: Menggulir irisan CT scan maju / mundur (slice scrolling).

2. 1 JARI TELUNJUK (Laser Pointer Bedah & Dwell Marking)
   - Acungkan hanya 1 jari telunjuk (jari lain tertekuk).
   - Pointer: Crosshair cyan mengikuti titik tunjuk pada viewport CT.
   - Dwell (1,4 detik / 42 frame): Tahan telunjuk diam pada target untuk
     menandai lesi patologis otomatis dengan retikel target.

3. 2 JARI (Telunjuk & Tengah - Ganti Windowing CT)
   - Tahan 2 jari tegak selama 0,5 detik (15 frame).
   - Fungsi: Mengganti preset kontras CT (Brain -> Bone -> Subdural).

4. 3 JARI (Bookmark Irisan CT)
   - Tahan 3 jari tegak selama 0,5 detik (15 frame).
   - Fungsi: Menandai/bookmark irisan CT aktif untuk referensi cepat.

5. 4 JARI (Laporan Suara Tanda Vital)
   - Tahan 4 jari tegak selama 0,5 detik (15 frame).
   - Fungsi: Membacakan ringkasan tanda vital pasien (HR, SpO2, Tekanan Darah).

6. 5 JARI (Telapak Terbuka - Sterile Gesture Lock)
   - Buka seluruh 5 jari selama 0,5 detik (15 frame).
   - Fungsi: Mengunci / menjeda deteksi gestur agar tidak terjadi input
     tidak disengaja saat memegang instrumen bedah. Ulangi untuk membuka kunci.

--------------------------------------------------------------------------------
3. PANDUAN PERINTAH SUARA (BAHASA INDONESIA & INGGRIS)
--------------------------------------------------------------------------------
Sistem dilengkapi perlindungan Half-Duplex (mikrofon otomatis dibisukan saat
sistem berbicara atau membunyikan alarm agar bebas feedback loop).
Rincian lengkap ada di "VOICE_COMMANDS_TUTORIAL.txt".

A. Perintah Suara Bahasa Indonesia (Mode: "ID Online"):
- "iris berikutnya" / "naik"       -> Pindah ke irisan CT berikutnya
- "iris sebelumnya" / "turun"      -> Pindah ke irisan CT sebelumnya
- "jendela otak"                   -> Preset Brain Window (L:40 W:80)
- "jendela tulang"                 -> Preset Bone Window (L:500 W:2000)
- "jendela subdural"               -> Preset Subdural Window (L:70 W:200)
- "simpan iris" / "bookmark"       -> Bookmark irisan aktif
- "tandai lesi" / "tandai target"  -> Tandai lesi pada posisi kursor
- "hapus tanda" / "bersihkan tanda"-> Hapus tanda lesi pada irisan aktif
- "tanda vital" / "status pasien"  -> Bacakan ringkasan tanda vital
- "detak jantung"                  -> Bacakan denyut jantung (HR)
- "saturasi" / "oksigen"           -> Bacakan saturasi SpO2
- "tekanan darah" / "tensi"        -> Bacakan tekanan darah arterial
- "hening alarm" / "matikan alarm" -> Heningkan alarm 2 menit (IEC 60601-1-8)
- "jeda kamera" / "kunci gestur"   -> Kunci pelacakan gestur
- "lanjut kamera" / "buka gestur"  -> Aktifkan kembali pelacakan gestur
- "bantuan"                        -> Panduan perintah suara

B. Perintah Suara Bahasa Inggris (Mode: "EN Offline" - Vosk):
- "next slice" / "next"            -> Irisan berikutnya
- "previous slice" / "previous"    -> Irisan sebelumnya
- "window brain" / "window bone" / "window subdural" -> Ganti preset CT
- "bookmark slice" / "save slice"  -> Bookmark irisan aktif
- "mark lesion" / "mark target"    -> Tandai lesi
- "clear markers" / "clear"        -> Hapus tanda pada irisan aktif
- "patient vitals" / "vitals"      -> Bacakan ringkasan tanda vital
- "heart rate" / "oxygen" / "blood pressure" -> Bacakan parameter spesifik
- "silence alarm" / "mute alarm"   -> Heningkan alarm 2 menit
- "pause camera" / "resume camera" -> Kunci / buka pelacakan gestur
- "help"                           -> Panduan suara

C. Mode Dikte Klinis ("Dictation ID"):
- Ucapkan catatan klinis bebas dalam Bahasa Indonesia untuk langsung dicatat
  dengan timestamp ke log intra-operatif (dapat diekspor ke berkas .txt).

--------------------------------------------------------------------------------
4. KONTROL KEYBOARD & MOUSE (CADANGAN REDUNDAN)
--------------------------------------------------------------------------------
- [SPASI]                : Kunci / Buka Deteksi Gestur (Gesture Lock)
- [PANAH KIRI/BAWAH/P]   : Irisan CT sebelumnya
- [PANAH KANAN/ATAS/N]   : Irisan CT berikutnya
- [W]                    : Siklus preset CT Window (Brain -> Bone -> Subdural)
- [B]                    : Bookmark irisan aktif
- [M]                    : Tandai lesi pada posisi kursor
- [C]                    : Hapus tanda pada irisan aktif
- [V]                    : Bacakan laporan tanda vital
- [A]                    : Heningkan alarm 2 menit (IEC 60601-1-8)
- [ESC] (di editor log)  : Kembalikan fokus keyboard dari catatan ke aplikasi
- [Scroll Mouse di CT]   : Ganti irisan CT langsung
- [Klik Mouse di CT]     : Tandai target lesi secara manual
