Halo Rekan Tim / Anggota Kelompok!
Paket ini sudah disiapkan lengkap agar bisa langsung dijalankan di laptop Windows

disertakan offline di dalam folder "models/".

--------------------------------------------------------------------------------
1. CARA MEMULAI (HANYA 3 LANGKAH)
--------------------------------------------------------------------------------

[LANGKAH 1] EKSTRAK FILE ZIP
- Pastikan file "OR_SterileAssist_SiapKirim.zip" sudah di-ekstrak terlebih dahulu!
  (Klik kanan file ZIP -> "Extract All..." / "Ekstrak Semua").
- PENTING: JANGAN menjalankan script langsung dari dalam file .ZIP karena Windows 
  membuat folder sementara (temporary) yang tidak dapat menyimpan virtual environment.

[LANGKAH 2] SETUP DEPENDENSI (Hanya Perlu Dilakukan Sekali Saja)
- Pastikan laptop terhubung ke internet.
- Dobel klik file:
    "1_SETUP_DEPENDENCIES.bat"
- Script otomatis akan:
  1. Memeriksa ketersediaan Python di laptop Anda (Python 3.10 / 3.11 / 3.12 / 3.13 / 3.14).
  2. Membuat Virtual Environment lokal terisolasi (.venv) di dalam folder ini.
  3. Menginstall semua library Python yang dibutuhkan secara otomatis.
- Jika laptop belum memiliki Python, ikuti petunjuk yang muncul di layar:
  Unduh di https://www.python.org/downloads/ dan CENTANG "[X] Add Python to PATH".
- Tunggu hingga muncul pesan "SETUP BERHASIL SELESAI!".

[LANGKAH 3] JALANKAN APLIKASI
- Anda dapat memilih salah satu cara berikut:
  * Opsi A: Dobel klik "2_JALANKAN_APLIKASI.bat"
    -> Menjalankan aplikasi bersamaan dengan jendela konsol/CMD (sangat berguna 
       untuk melihat log deteksi kamera, frame rate, dan status audio).
  * Opsi B: Dobel klik "3_JALANKAN_TANPA_CMD.vbs"
    -> Menjalankan aplikasi secara langsung dan senyap (silent) tanpa jendela hitam CMD, 
       tampilan bersih seperti aplikasi Windows profesional.

--------------------------------------------------------------------------------
2. PANDUAN GESTUR TANGAN (SURGICAL HAND GESTURES)
--------------------------------------------------------------------------------
Arahkan tangan menghadap kamera webcam Anda pada jarak sekitar 0.5 - 1.2 meter:

1. 🤏 PINCH (Cubit Telunjuk & Ibu Jari)
   - Tempelkan ujung jari telunjuk dan ibu jari, lalu gerakkan tangan naik/turun.
   - Fungsi: Menjelajahi irisan CT scan (Slice scrolling maju / mundur).

2. ☝ 1 JARI TELUNJUK (Laser Pointer & Penanda Target Lesi)
   - Acungkan hanya 1 jari telunjuk (seperti menunjuk).
   - Fungsi Pointer: Crosshair biru muda (cyan) akan melacak titik tunjuk di layar CT.
   - Fungsi Dwell Marking: Tahan telunjuk diam di posisi target lesi selama 1.4 detik.
     Lingkaran progres hijau akan berputar dan otomatis menandai lesi patologis!

3. ✌ 2 JARI TELUNJUK & TENGAH (Ganti Preset Windowing CT)
   - Acungkan 2 jari tegak selama 0.5 detik.
   - Fungsi: Mengganti kontras CT secara siklis (Brain Window -> Bone Window -> Subdural).

4. 🤟 3 JARI (Bookmark Irisan CT)
   - Acungkan 3 jari (ibu jari, telunjuk, tengah atau telunjuk, tengah, manis) selama 0.5 detik.
   - Fungsi: Menyimpan / bookmark irisan CT saat ini untuk referensi cepat intra-operatif.

5. 🖖 4 JARI (Laporan Suara Status Pasien)
   - Acungkan 4 jari selama 0.5 detik.
   - Fungsi: Sistem akan membacakan rangkuman tanda vital pasien (Heart Rate, SpO2, Tekanan Darah).

6. 🖐 5 JARI (Telapak Terbuka - Sterile Gesture Lock)
   - Buka seluruh 5 jari telapak tangan selama 0.5 detik.
   - Fungsi: Mengunci / Menjeda (Pause) pembacaan gestur agar tidak terjadi input tak disengaja 
     saat dokter sedang memegang instrumen bedah. Buka 5 jari lagi untuk Resume.

--------------------------------------------------------------------------------
3. PANDUAN PERINTAH SUARA (VOICE COMMANDS)
--------------------------------------------------------------------------------
Sistem dilengkapi pengenal suara dwibahasa (Bahasa Indonesia & Bahasa Inggris):

Perintah Suara Bahasa Indonesia (Mode Default "ID Online"):
- "iris berikutnya" / "naik"      -> Pindah ke irisan CT berikutnya
- "iris sebelumnya" / "turun"     -> Pindah ke irisan CT sebelumnya
- "jendela otak"                  -> Pindah ke preset Brain Window
- "jendela tulang"                -> Pindah ke preset Bone Window
- "jendela subdural"              -> Pindah ke preset Subdural Window
- "simpan iris" / "bookmark"      -> Simpan bookmark irisan aktif
- "tandai lesi"                   -> Tandai titik lesi pada posisi kursor saat ini
- "hapus tanda"                   -> Bersihkan tanda lesi pada irisan aktif
- "tanda vital" / "status pasien" -> Dengarkan rangkuman tanda vital lengkap
- "detak jantung"                 -> Dengarkan nilai denyut jantung (HR)
- "saturasi"                      -> Dengarkan persentase SpO2 darah
- "tekanan darah"                 -> Dengarkan nilai tekanan darah arterial
- "hening alarm"                  -> Matikan/bungkam alarm medis selama 2 menit (IEC 60601-1-8)
- "jeda kamera" / "kunci gestur"  -> Kunci tracking gestur tangan
- "lanjut kamera" / "buka gestur" -> Buka kembali tracking gestur
- "bantuan"                       -> Panduan suara interaktif

--------------------------------------------------------------------------------
4. KONTROL CADANGAN KEYBOARD & MOUSE (FAIL-SAFE REDUNDANCY)
--------------------------------------------------------------------------------
Untuk keandalan penuh, seluruh fitur dapat dikendalikan dengan tombol keyboard:
- [SPASI]            : Kunci / Buka Deteksi Gestur (Gesture Lock)
- [PANAH ATAS / BAWAH]: Navigasi Irisan CT (Next / Prev Slice)
- [ANGKA 1]          : Preset Brain Window
- [ANGKA 2]          : Preset Bone Window
- [ANGKA 3]          : Preset Subdural Window
- [HURUF B]          : Simpan Bookmark Irisan
- [HURUF M]          : Tandai Titik Lesi Bedah (Mark Target)
- [HURUF C]          : Hapus Tanda Lesi pada Irisan Aktif
- [HURUF A]          : Heningkan Alarm Pasien 2 Menit (IEC 60601-1-8 Silence)
- [HURUF V]          : Dengarkan Laporan Suara Tanda Vital
- [HURUF H]          : Bantuan Suara
- [ESC] / [HURUF Q]  : Keluar dari Aplikasi

--------------------------------------------------------------------------------
5. FITUR BIOMEDIS UNGGULAN
--------------------------------------------------------------------------------
1. Standar Alarm Medis IEC 60601-1-8:
   Sintesis nada peringatan medis Low, Medium, dan High Priority burst secara matematis.
2. Pitch Sonifikasi SpO2:
   Tinggi nada denyut jantung merefleksikan tingkat saturasi oksigen (SpO2) pasien 
   secara real-time (nada semakin turun jika saturasi oksigen menurun).
3. Deteksi Kehadiran Wajah Dokter (BlazeFace Auto-Lock):
   Jika dokter melangkah mundur atau berpaling jauh dari zona steril, sistem otomatis 
   menghentikan eksekusi gestur untuk mencegah kesalahan input.
4. Perlindungan Half-Duplex Akustik:
   Mikrofon otomatis dimatikan sejenak ketika sistem sedang berbicara atau membunyikan 
   alarm, mencegah suara sistem terdengar kembali ke mikrofon (anti-feedback loop).

--------------------------------------------------------------------------------
6. TROUBLESHOOTING & PERTANYAAN UMUM
--------------------------------------------------------------------------------
T: Kamera tidak muncul atau layar video hitam?
J: Pastikan webcam laptop tidak sedang digunakan oleh aplikasi lain (Zoom, Teams, dsb). 
   Gunakan dropdown "Kamera" di panel kanan atas untuk memilih ID kamera lain (0 atau 1).

T: Suara alarm tidak berbunyi?
J: Periksa output audio speaker Anda dan pastikan volume laptop tidak dalam kondisi Mute.

T: Apakah bisa dijalankan tanpa koneksi internet?
J: BISA. Model pengenal gestur dan wajah sudah tersimpan lokal di folder "models/". 
   Untuk voice recognition offline, ubah mode suara di panel audio ke "EN Offline (Vosk)".

T: Ingin menjalankan test otomatis?
J: Buka terminal CMD di folder ini, lalu jalankan:
   .venv\Scripts\python.exe test_or_sterile_assist.py
   Semua 22 unit test akan dieksekusi secara otomatis.
